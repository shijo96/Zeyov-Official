# Zeyov-Official

Shopify theme for **[zeyov.com](https://zeyov.com)** — Zeyov, premium own-brand T-shirts from Ernakulam, Kerala.

## What's inside

| Folder | Contents |
|---|---|
| `layout/` | Page shell (`theme.liquid`): fonts, favicon, header/footer |
| `sections/` | Page sections — clothing rack hero (normal + Christmas), Zeyov Studio, product page, reviews, FAQ, policies, track order, testimonials |
| `snippets/` | Reusable parts — product card, rating stars, icons |
| `templates/` | Page templates (home, product, Studio, FAQ, policies, track order…) |
| `assets/` | CSS, JavaScript, images and icons |
| `config/` | Theme settings |
| `locales/` | Text translations |

## Key features

- **Zeyov Studio** – design your own tee with live mockup and instant T-shirt + printing price
- **Clothing rack hero** with a festive Christmas version
- **Pre-booking** for out-of-stock sizes (full payment, ₹ advance, or request without payment)
- **Delivery estimate** on every product (printed in 24–48 hrs, delivered in 7–8 days)
- **Reviews without login**, with photo upload and star ratings
- **Track order without login**, FAQ page and styled policy pages

## Hidden system products (do not delete in Shopify admin)

- `zeyov-studio-tee` – all Zeyov Studio prices
- `pre-booking-advance` – pre-booking advance payment
- `review-photo-upload` – photo uploads in reviews

## Connect to Shopify

Shopify admin → **Online Store → Themes → Add theme → Connect from GitHub** → choose `shijo96/Zeyov-Official`, branch `main`.
